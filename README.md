# Analisando Videoclipes com Gemini API
Projeto experimental utilizando a Gemini API para análise multimodal de vídeos, explorando interpretação visual, narrativa, estética e emoções em videoclipes.
Neste projeto, utilizamos o videoclipe de White Mustang, da Lana Del Rey, como estudo de caso para testar diferentes estratégias de prompting com modelos multimodais.

Toda a explicação do desenvolvimento pode ser encontrado no Medium, [acessando aqui](https://medium.com/@lauradatatalks/analisando-o-videoclipe-da-lana-del-rey-com-gemini-api-388757d34aa0)

### 🧠 O que é multimodalidade?
Modelos multimodais conseguem trabalhar com diferentes tipos de entrada além de texto, como:

* imagens
* áudio
* vídeos
* documentos
  
Com a Gemini API, podemos combinar esses formatos dentro do mesmo contexto de análise.

### 🚀 Tecnologias utilizadas

* Python
* Gemini API
* Google AI Studio
